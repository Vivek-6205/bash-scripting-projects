# bash-scripting-projects
Collection of Linux Shell Scripting projects for automation, system monitoring, resource tracking, and DevOps practice using Bash scripting.


A collection of Bash/Shell scripting projects focused on Linux automation, system monitoring, and DevOps practice.

This repository contains beginner-to-intermediate level shell scripting projects designed to improve Linux administration, automation, and scripting skills.

---

## Technologies Used

- Bash / Shell Scripting
- Linux
- awk
- sed
- grep
- Cron Jobs

---

## Projects Included

### 1. RAM Usage Monitor
Checks current RAM usage and displays memory statistics.

### 2. Disk Usage Monitor
Monitors disk space usage and helps identify storage consumption.

### 3. URL Status Checker
Checks whether a website or URL is reachable and active.

### 4. Random Number Generator
Generates random numbers using shell scripting logic.

### 5. System Monitoring Script
Displays important system information such as CPU, memory, uptime, and disk usage.

### 6. Live Timer Script
Runs a live timer/countdown in the terminal.
